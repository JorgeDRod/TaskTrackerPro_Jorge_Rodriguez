# Task Tracker Pro

A native Android task and project cost management application developed as my Software Engineering capstone at Western Governors University.

Task Tracker Pro allows users to create and manage hourly and fixed-price tasks, calculate project costs, persist task data locally, search and edit existing tasks, and generate task summary reports.

## Features

- Create, view, search, update, and delete tasks
- Support for hourly and fixed-price billing models
- Automatic cost calculation for hourly tasks
- Local data persistence using Android Room
- Task search and editing
- Task summary report generation
- Input validation

## Technology Stack

- Java
- Android SDK
- Room
- ViewModel
- LiveData
- RecyclerView
- Gradle

## Software Engineering Concepts

The project demonstrates several software engineering concepts, including:

- Object-Oriented Programming
- CRUD operations
- Local data persistence
- Android architecture components
- Separation of application layers
- Input validation

## Application Architecture

The application separates the Android user interface, application logic, and local data persistence.

The architecture uses Android architecture components with Room providing local database persistence.

## Project Background

Task Tracker Pro was developed as the capstone project for my Bachelor of Science in Software Engineering at Western Governors University.

The original source code remains private in accordance with academic and course repository requirements. This repository provides a portfolio presentation of the application, its functionality, architecture, and technical concepts.
